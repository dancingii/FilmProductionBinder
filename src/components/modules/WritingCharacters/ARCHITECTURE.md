# Writing Characters Module

Writing Characters is the draft/story-only character system for the Writing workflow.

Future ownership:

- `writingCharacterId`
- Character display name
- Aliases and alternate names
- Description
- Age range
- Story notes
- Arc notes
- Relationship notes
- First appearance
- Writing scene references
- Autocomplete support data for Writing Script

Rules:

- Must not mutate production Characters directly.
- Must not write cast, call sheet, wardrobe, makeup, props, continuity, or production character relationships.
- Later production character creation/linking must happen only through the explicit Writing-to-Pre-Production handoff layer.

For Phase 4A this is a placeholder only and is not routed by the app.
